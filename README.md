# 이지영 포트폴리오

콘텐츠 마케터 · 캠페인 기획자 이지영의 포트폴리오와 마케팅 노트 사이트입니다.

- 사이트 주소: https://jeeeieee.github.io
- 글 관리: https://jeeeieee.github.io/admin

## 글 쓰는 법

1. `/admin` 에 들어가 **액세스 토큰으로 로그인**을 누릅니다. (한 번 로그인하면 그 브라우저에서는 계속 로그인돼 있어요.)
2. **사이트 내용 → 마케팅 노트**를 엽니다.
3. **글 추가**를 누르고 제목, 날짜, 주제, 본문을 씁니다. 사진은 본문 편집기에서 바로 넣을 수 있어요.
4. **저장**을 누르면 1~2분 뒤 사이트에 반영됩니다.

캠페인은 **사이트 내용 → 캠페인 파일**에서 같은 방법으로 추가하고 고칩니다. 목록에서 끌어 순서를 바꾸면 메인 페이지 순서도 바뀝니다.

휴대폰에서 쓰려면 컴퓨터에서 로그인한 상태로 **모바일로 로그인**을 누르고, 휴대폰으로 QR 코드를 찍으면 됩니다.

## 폴더 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 사이트 화면 (디자인, 소개, 연락처) |
| `app.js` | 글과 캠페인을 불러와 화면에 그리는 코드 |
| `data/notes.json` | 마케팅 노트 글 (글 관리 화면에서 수정) |
| `data/cases.json` | 캠페인 파일 (글 관리 화면에서 수정) |
| `admin/` | 글 관리 화면 (Sveltia CMS) |
| `images/uploads/` | 글에 넣은 사진 |

소개, 연락처, 첫 화면 문구는 `index.html` 안에 있습니다.

## 주의

- 액세스 토큰은 비밀번호와 같아요. 다른 사람에게 보내지 마세요.
- 이 저장소는 공개(Public)라서 올린 글과 사진은 누구나 볼 수 있어요. 사이트에 공개할 내용만 올려 주세요.
